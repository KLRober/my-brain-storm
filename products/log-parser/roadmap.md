# log-parser – Roadmap

## Phase 1: Log parsing and regex extraction
- [ ] Parse authentication log files (auth.log, syslog)
- [ ] Define regex patterns for common security events
- [ ] Extract events from raw log data

## Phase 2: Event classification and statistics
- [ ] Classify events by type (failed login, success, SSH, etc.)
- [ ] Count and aggregate events
- [ ] Track event frequency over time

## Phase 3: Report generation (CSV + console)
- [ ] Output results to console
- [ ] Export events and statistics to CSV format
- [ ] Summary report generation

## Phase 4: Improvements
- [ ] Better regex patterns
- [ ] Performance optimization
- [ ] Support for new log formats

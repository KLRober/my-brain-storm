# log-parser

> A simple Python tool to parse and analyze security logs.

## About

This tool reads authentication logs (like Linux auth.log or syslog), extracts security events using regex patterns, and generates basic statistics and reports.

## Features

- Parse security log files
- Extract events using regular expressions
- Count events by type (failed logins, successful authentication, SSH attempts, etc.)
- Generate reports in console or CSV format

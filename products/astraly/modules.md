# Astraly – Core Modules

## Image Optimizer

A compression and conversion engine built with **Pillow**. Handles:
- Resizing images
- Format conversion
- Image optimization

## PDF Manager

Logic layer responsible for:
- Merging PDF documents
- Splitting PDF files
- Manipulating PDF content

## Smart Organizer

A classification engine that sorts files based on:
- File extensions
- Metadata analysis

Automatically organizes files into meaningful folder structures.
